# Product Overview

Bird Platform is a full-stack birdwatching product that combines identification, community participation, moderation, and cloud-backed application services.

## User-facing features

- browse bird species
- view detailed species information
- create predictions with image, sound, notes, and location
- update or delete saved predictions
- share predictions to the community
- rate, react to, and comment on community posts
- switch theme mode
- send support messages
- review moderation case updates
- delete an account in-app

## Admin-facing features

- review support messages and send replies
- manage moderation cases through a forward-only workflow
- review user responses after moderation decisions
- manage species media
- set default images and image order
- manage song / call quality metadata

## Platform capabilities

The platform brings together:

- mobile product design
- backend API design
- media pipeline design
- moderation and safety workflows
- Firebase integration
- real-device testing
- cloud deployment and service operations
- AI-assisted product capabilities
