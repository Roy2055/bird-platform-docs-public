## What the visual shows

- `Comment / complaint` is the support lane with a two-way conversation loop.
- `Report content` is the content moderation lane with binary action / no-action outcomes.
- `Report user` is the trust and safety lane with escalating account-level outcomes.
- `Block user` is the self-serve safety lane with no human review queue.

## Visual key

- Blue nodes represent comment / complaint flow.
- Amber nodes represent report content flow.
- Coral nodes represent report user flow.
- Purple nodes represent block user flow.
- Red nodes represent enforcement actions.
- Teal nodes represent resolution states.
